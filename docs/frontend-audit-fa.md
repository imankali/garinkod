# بررسی فرانت‌اند گرین کود — ۲۲ اوت ۲۰۲۶

## صفحات بررسی‌شده

| صفحه/مسیر | وضعیت بررسی | اقدام انجام‌شده |
|---|---|---|
| `/` فروشگاه | کاتالوگ، فیلتر، جست‌وجو، سبد، wishlist و مقایسه | فیلتر و مرتب‌سازی غیرواقعی امتیاز حذف شد؛ نمایش امتیاز جعلی حذف شد؛ selector محصول کشاورزی تا زمان وجود دادهٔ واقعی crop tag پنهان می‌ماند. |
| `/products` و `/products/:slug` | مسیر کاتالوگ و جزئیات | مسیرهای معتبر، جزئیات محصول و fallback تصویر بررسی شدند. |
| `/login` | ورود/ثبت‌نام | flow موجود بررسی شد؛ برای نسخهٔ جهانی باید phone-first/OAuth/2FA به roadmap منتقل شود. |
| `/profile` | حساب کاربری | با مرکز حساب حرفه‌ای جایگزین شد: overview، خریدها، غرفه و فروش، اطلاعات شخصی/تحویل. |
| `/orders` | پیگیری سفارش | مسیر و لیست سفارش‌های کاربر برقرار است. |
| `/checkout` | سفارش | بدون ادعای پرداخت آنلاین؛ ثبت سفارش و هماهنگی امن‌تر. |
| `/services` | خدمات مزرعه | درخواست خدمت واقعی به API متصل است. |
| `/farmer-sell` | تأمین از کشاورز | درخواست فروش محصول واقعی به API متصل است. |
| `/marketplace` | بازار و غرفه | لیست آگهی، ساخت غرفه و moderation backend موجود است. |
| Header/Mobile nav/Profile menu | ناوبری | لینک‌های 404 مربوط به wishlist/settings/blog/contact حذف یا به مسیر معتبر هدایت شدند. |

## کمبودهای شناسایی‌شده و اصلاح‌شده

### انجام شد

- زیرساخت چندزبانه با localeهای `fa`، `en` و `ar` اضافه شد.
  - انتخاب زبان در Header دسکتاپ و موبایل
  - ذخیره انتخاب در `localStorage`
  - تغییر خودکار `lang` و `dir` به RTL/LTR
  - ترجمهٔ navigation و مرکز حساب در سه زبان
  - typography مناسب برای رابط انگلیسی
- پروفایل ساده به مرکز حساب خریدار/فروشنده ارتقا یافت.
- فروشنده از داخل profile می‌تواند غرفه بسازد و آگهی محصول را برای بررسی ثبت کند.
- خریدار سفارش‌های حساب، وضعیت و مبلغ را در profile می‌بیند.
- لینک‌های منوی پروفایل که به صفحات inexist/404 می‌رفتند اصلاح شدند.
- رتبه‌بندی و فیلتر امتیاز ساختگی از کاتالوگ و search برداشته شد؛ تا دادهٔ review واقعی ایجاد نشود نمایش داده نمی‌شود.
- crop selector که با دادهٔ خالی نتایج صفر تولید می‌کرد، فقط با crop tag واقعی ظاهر می‌شود.
- fallback جست‌وجوی صوتی که عبارت تصادفی وارد می‌کرد حذف شد؛ اکنون پیام شفاف پشتیبانی‌نشدن نمایش داده می‌شود.
- widget هواشناسی با برچسب «نمونهٔ نمایشی» شفاف شد؛ دیگر به‌عنوان داده زنده امروز ادعا نمی‌شود.
- آپلود عکس مشاوره که قبلاً upload موفق شبیه‌سازی می‌کرد، صادقانه به کانال واتس‌اپ راهنمایی می‌کند تا API واقعی ساخته شود.
- claimهای غیرقابل‌اثباتِ مجوز، تخفیف و زمان قطعی ارسال از TopBar/سبد حذف یا اصلاح شدند.

## مواردی که هنوز باید ساخته شوند

### P0 — قبل از توسعه بین‌المللی یا رشد ترافیک

1. **ترجمهٔ کامل محتوا**: چارچوب i18n آماده است اما متن‌های legacy در widgetها، checkout، marketplace و صفحات تخصصی هنوز فارسی‌اند. ترجمهٔ خودکار/ماشینی نباید جای محتوای کارشناسی بازبینی‌شده را بگیرد.
2. **دادهٔ واقعی محصول**: برند، review، rating، crop tag، کاربرد، هشدار، گواهی و موجودی دقیق باید از backend بیاید. نمایش دادهٔ فرضی درست نیست.
3. **پرداخت زرین‌پال و lifecycle سفارش**: callback verify، انقضای پرداخت، لغو با بازگرداندن موجودی، refund و ledger مالی لازم است.
4. **بازار فروشندگان**: KYC/KYB، قوانین marketplace، payout، سفارش marketplace، dispute و chat امن هنوز در حد foundation هستند.

### P1 — تجربه کاربر و دسترس‌پذیری

- pagination یا infinite loading برای کاتالوگ بزرگ
- URL قابل اشتراک برای search/filter/sort و بازگرداندن state بعد از refresh
- empty/error/retry state استاندارد در همه queryها؛ اکنون برخی صفحه‌ها فقط empty state دارند
- focus trap، Escape و بازگرداندن focus برای همه modal/drawerها
- keyboard navigation کامل برای mega menu، فیلتر و dropdownها
- صفحهٔ 404 حرفه‌ای با search و لینک‌های کاربردی
- تنظیمات اعلان، حریم خصوصی، حذف حساب، export داده و مدیریت نشانی‌های متعدد
- wishlist سمت سرور برای کاربران واردشده؛ localStorage فعلی بین دستگاه‌ها sync نمی‌شود

### P2 — جهانی‌سازی واقعی

- currency و واحد: تومان/ریال، USD/EUR، kg/ton/lb/hectare/acre
- شماره تلفن و نشانی منطقه‌ای، timezone، تقویم و قوانین مالیاتی هر کشور
- کاتالوگ و محتوای حقوقی محلی، محصولات مجاز و محدودیت سموم هر بازار
- translation management، glossary کشاورزی، review انسانی، hreflang و sitemap localized
- RTL/LTR QA در همه layoutها، اعداد، جدول‌ها و نمودارها

### P3 — داده و یکپارچگی

- API واقعی هواشناسی با منبع، timestamp، location permission و fallback امن
- chat/ticket با SLA، upload امن، antivirus scan و retention policy
- notification centre، SMS/email/WhatsApp policy و consent
- analytics رویدادهای فروش بدون نقض privacy
- feature flag و A/B test برای rollout خدمات جدید
